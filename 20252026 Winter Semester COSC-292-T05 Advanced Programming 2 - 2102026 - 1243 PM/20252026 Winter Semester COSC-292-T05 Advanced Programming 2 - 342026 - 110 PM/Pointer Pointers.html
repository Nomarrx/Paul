Lesson — Pointers to Pointers

Learning Outcome(s): LO5 — Develop code to reference and manipulate static memory with pointers.

Assessment alignment: Midterm 2 (Pointers & pointer-to-pointer concepts).

Introduction to Pointers to Pointers

Pointers store an address. Pointers are also variables, so each pointer itself has an address. A pointer to a pointer stores the address of a pointer. This is required when a function must change a pointer in the caller (e.g., make a caller’s pointer point somewhere else), or when working with arrays of pointers (like “jagged” arrays).

Warm-up: myIndexOf (no pointer-to-pointer)

Goal

Find the index (0-based) of the first occurrence of a character in a string; return -1 if not found.

Example call (main)

#include <stdio.h>
#include <stdlib.h>

int myIndexOf(const char* cPtr, char cSeek);

int main(void)
{
    char cTestString[] = "It's a beautiful day, isn't it?";
    int iLocation = myIndexOf(cTestString, 's');

    printf("The position of the character is %d\n\n", iLocation);
    return EXIT_SUCCESS;
}

 

Accordion

Please attempt the solution first
Function solution
/*
* Function: myIndexOf
* Purpose: Return the 0-based index of the first occurrence of cSeek in cPtr, or -1 if not found.
* Parameters: cPtr - pointer to null-terminated string
*             cSeek - character to find
* Returns: index or -1
*/
int myIndexOf(const char* cPtr, char cSeek)
{
    int iLocation = 0;

    while (*cPtr) // while not at null terminator
    {
        if (*cPtr == cSeek)
        {
            return iLocation;
        }
        cPtr++;
        iLocation++;
    }
    return -1;
}

 

Exercise 1 — Counting with pass-by-value vs pointer parameter

Task

Write myIndexOfAndCount that returns the index of the first occurrence and also updates a count of how many times the character appears in the string.

What to notice

  • In C, arguments are passed by value — a copy is made.
  • To update a caller’s variable, pass its address and write through a pointer.

Incorrect (shows the problem)

int myIndexOfAndCount(const char* cPtr, char cSeek, int iCount)
/* BUG: iCount is a copy; caller's count will not change */
{
    int iLocation = -1;
    int iPosition = 0;

    while (*cPtr)
    {
        if (*cPtr == cSeek)
        {
            if (iLocation == -1) { iLocation = iPosition; }
            iCount++;
        }
        cPtr++;
        iPosition++;
    }
    printf("In the function, count is %d\n", iCount);
    return iLocation;
}

Correct (use int*) — Solution

Function solution
/*
* Function: myIndexOfAndCount
* Purpose: Return first index of cSeek in cPtr (or -1) and set *iCountPtr to total occurrences.
*/
int myIndexOfAndCount(const char* cPtr, char cSeek, int* iCountPtr)
{
    int iLocation = -1;
    int iPosition = 0;
    *iCountPtr = 0;

    while (*cPtr)
    {
        if (*cPtr == cSeek)
        {
            if (iLocation == -1) { iLocation = iPosition; }
            (*iCountPtr)++;
        }
        cPtr++;
        iPosition++;
    }
    printf("In the function, count is %d\n", *iCountPtr);
    return iLocation;
}

Example call (main)

char cTestString[] = "It's a beautiful day, isn't it?";

printf("The position of the character is %d\n", iLocation);
printf("The count of the character is %d\n\n", iCount);

Exercise 2 — When you must change a pointer: need a char**

Task

Extend the function to also set a pointer to the last occurrence of the character in the string.

What to notice

  • To change a pointer in the caller, the callee needs the address of that pointer → use char**.
  • *cPtrToPtr is the original pointer; **cPtrToPtr is the character at that location.

Incorrect (takes char*, won’t update caller’s pointer)

int myIndexOfAndCountAndLastPosition(const char* cPtr, char cSeek, int* iCountPtr,
                                     char* cLastPtr /* BUG: not a pointer-to-pointer */)
{
    int iLocation = -1;
    int iPosition = 0;

    *iCountPtr = 0;
    cLastPtr = NULL; // modifies only the local copy

    while (*cPtr)
    {
        if (*cPtr == cSeek)
        {
            if (iLocation == -1) { iLocation = iPosition; }
            (*iCountPtr)++;
            cLastPtr = (char*)cPtr; // only updates the local copy
        }
        cPtr++;
        iPosition++;
    }
    return iLocation;
}

Correct (use char**) — Solution

 

Accordion

Please attempt the solution first
Function solution
/*
* Function: myIndexOfAndCountAndLastPosition
* Purpose: Return first index; set *iCountPtr to total occurrences; set *cPtrToPtr to
*          address of last occurrence (or NULL if not found).
*/
int myIndexOfAndCountAndLastPosition(const char* cPtr, char cSeek, int* iCountPtr,
                                     char** cPtrToPtr)
{
    int iLocation = -1;
    int iPosition = 0;

    *iCountPtr = 0;
    *cPtrToPtr = NULL;

    while (*cPtr)
    {
        if (*cPtr == cSeek)
        {
            if (iLocation == -1) { iLocation = iPosition; }
            (*iCountPtr)++;
            *cPtrToPtr = (char*)cPtr; // update caller's pointer
        }
        cPtr++;
        iPosition++;
    }

    if (*cPtrToPtr != NULL)
    {
        printf("In the function, the character pointed at is %c at %p\n",
               **cPtrToPtr, *cPtrToPtr);
    }
    return iLocation;
}

 

Example call (main)

char cTestString[] = "It's a beautiful day, isn't it?";
int iLocation, iCount = 0;
char* cLastPtr = NULL;

iLocation = myIndexOfAndCountAndLastPosition(cTestString, 's', &iCount, &cLastPtr);
printf("The position of the character is %d\n", iLocation);
printf("The count of the character is %d\n\n", iCount);

if (cLastPtr != NULL)
{
    printf("The character at location %p is %c\n", (void*)cLastPtr, *cLastPtr);
    printf("The string starting at that character is %s\n\n", cLastPtr);
}

Key takeaways

  • C passes arguments by value (copies).
  • To change a caller’s variable, pass its address → use a pointer and dereference in the function.
  • To change a caller’s pointer, pass its address → use a pointer-to-pointer (e.g., char**).
  • *ptrToPtr gives you the original pointer; **ptrToPtr gives the value at that pointed location.

Example — trimRight: modify a caller’s pointer using char**

Test driver

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void trimRight(char** cPtrToPtr, int iNumChars);

void testTrimRight(void)
{
    char cArray[] = "Michael";
    char* cPtr = (char*)malloc((strlen(cArray) + 1) * sizeof(char));
    strcpy(cPtr, cArray);

    printf("cPtr: %s\n", cPtr);
    printf("The address stored by cPtr is %p\n", (void*)cPtr);
    printf("The address of cPtr is %p\n\n", (void*)&cPtr);

    trimRight(&cPtr, 3);

    printf("cPtr is now: %s\n", cPtr);
    printf("The address stored by cPtr is %p\n", (void*)cPtr);
    printf("The address of cPtr is %p\n\n", (void*)&cPtr);

    free(cPtr);
    cPtr = NULL;
}

Function (solution)

 

Accordion

Please attempt the solution first
Function solution
/*
* Purpose: Trim iNumChars characters from the right of a dynamically allocated string.
*          Replace the caller's pointer with a new allocation containing the trimmed text.
*/
void trimRight(char** cPtrToPtr, int iNumChars)
{
    // Original pointer in the caller:
    char* cOriginalPtr = *cPtrToPtr;

    int newLen = (int)strlen(cOriginalPtr) - iNumChars;
    if (newLen < 0) { newLen = 0; }

    // Allocate new string and copy
    *cPtrToPtr = (char*)malloc((newLen + 1) * sizeof(char));
    memcpy(*cPtrToPtr, cOriginalPtr, newLen * sizeof(char));
    *(*cPtrToPtr + newLen) = '\0';

    // Free old string
    free(cOriginalPtr);
}

We passed &cPtr into trimRight. Inside the function, *cPtrToPtr is the caller’s pointer. Assigning a new allocation to *cPtrToPtr replaces the caller’s pointer safely.

Accordion

Function solution
int findChar(char* cStringPtr, char cCharToFind, char** cPtrPtr)
{
    int location = 0;

    while (*cStringPtr)
    {
        if (*cStringPtr == cCharToFind)
        {
            *cPtrPtr = cStringPtr; // set caller's pointer
            return location;
        }
        location++;
        cStringPtr++;
    }

    *cPtrPtr = NULL;
    return -1;
}

 

Example — 2D Jagged Array (array of pointers)

A 2D jagged array is modeled as an array of pointers (each row can have a different length). The top-level value is a char**: a pointer to an array of char* pointers, one per row.

Driver

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char** createJaggedArray(int iRowSizes[], int iNumRows);
char* allocateRow(int iRowSize);
void printArrayOfStrings(char** cPtrPtr, int iRows);

void testJaggedArray(void)
{
    int iRowSizes[] = { 4, 6, 5 };
    int iRows = (int)(sizeof(iRowSizes) / sizeof(iRowSizes[0]));

    char** cPtrPtr = createJaggedArray(iRowSizes, iRows);

    // Fill rows using different techniques
    cPtrPtr[0][0] = 'M'; cPtrPtr[0][1] = 'e'; cPtrPtr[0][2] = 'l'; cPtrPtr[0][3] = '\0';

    *(*(cPtrPtr + 1) + 0) = 'C';
    *(*(cPtrPtr + 1) + 1) = 'h';
    *(*(cPtrPtr + 1) + 2) = 'r';
    *(*(cPtrPtr + 1) + 3) = 'i';
    *(*(cPtrPtr + 1) + 4) = 's';
    *(*(cPtrPtr + 1) + 5) = '\0';

    strcpy(cPtrPtr[2], "Mark");

    printArrayOfStrings(cPtrPtr, iRows);

    // Free ALL allocations
    for (int i = 0; i < iRows; i++)
    {
        free(cPtrPtr[i]);
        cPtrPtr[i] = NULL;
    }
    free(cPtrPtr);
    cPtrPtr = NULL;
}

Allocation + helpers

char** createJaggedArray(int iRowSizes[], int iNumRows)
{
    char** cPtrPtr = (char**)malloc(iNumRows * sizeof(char*));

    for (int i = 0; i < iNumRows; i++)
    {
        cPtrPtr[i] = allocateRow(iRowSizes[i]);
    }
    return cPtrPtr;
}

char* allocateRow(int iRowSize)
{
    char* cPtr = (char*)malloc(iRowSize * sizeof(char));
    cPtr[0] = '\0';
    return cPtr;
}

void printArrayOfStrings(char** cPtrPtr, int iRows)
{
    for (int i = 0; i < iRows; i++)
    {
        printf("String %d is: %s\n", i, cPtrPtr[i]);
    }
}

Exercise - Doubles array + pointer to the max

Learning goals

  • Return a dynamically allocated array of doubles and its size through an int*.
  • Also set a caller’s pointer to the max element using a double**.

Task

  1. Prompt for how many doubles to read. Allocate an array dynamically.
  2. Read values using scanf_s("%lf", ...) (or scanf, depending on your toolchain).
  3. Track the max value and set *maxPtrPtr to point at that element.
  4. Return the array; set *iArraySizePtr to the count.

Starter test function

#include <stdio.h>
#include <stdlib.h>
#include <float.h> // DBL_MAX

double* getDynamicDoubles(int* iArraySizePtr, double** maxPtrPtr);

void testDoubleArrayWithMax(void)
{
    int iArraySize = 0;
    double* dMaxPointer = NULL;
    double* dArray = getDynamicDoubles(&iArraySize, &dMaxPointer);

    for (int i = 0; i < iArraySize; i++)
    {
        printf("Double #%d: %lf\n", i, dArray[i]);
    }

    if (dMaxPointer)
    {
        printf("The max value is at %p and is %lf\n", (void*)dMaxPointer, *dMaxPointer);
    }

    free(dArray);
    dArray = NULL;
}

Solution: getDynamicDoubles

 

Accordion

Please attempt the solution first
Function solution
double* getDynamicDoubles(int* iArraySizePtr, double** maxPtrPtr)
{
    int n = 0;
    printf("How many doubles would you like to enter? ");
    scanf_s("%d", &n);
    *iArraySizePtr = n;

    double* dArray = (double*)malloc(n * sizeof(double));

    double maxVal = -DBL_MAX;
    *maxPtrPtr = NULL;

    for (int i = 0; i < n; i++)
    {
        printf("Enter a double: ");
        scanf_s("%lf", dArray + i); // or &dArray[i]

        if (i == 0 || dArray[i] > maxVal)
        {
            maxVal = dArray[i];
            *maxPtrPtr = dArray + i; // points into the array
        }
    }

    return dArray;
}

 

What to notice

  • We used double** maxPtrPtr so the function can set the caller’s pointer.
  • We used int* iArraySizePtr so the function can set the size for the caller.
  • Always free the returned array in the caller when done.

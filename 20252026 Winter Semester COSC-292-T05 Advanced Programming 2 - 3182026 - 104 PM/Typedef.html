Lesson — Typedefs in C

Learning Outcome(s): LO5 — Develop code using custom type names and type abstractions.

Assessment alignment: Midterm 1 (Typedefs & type rewriting).

What is typedef?

typedef allows you to create an additional name (“alias” or “synonym”) for an existing C type. Unlike #define, it is handled by the compiler, not the preprocessor.

Syntax

typedef ExistingType NewType;

Important: typedef does NOT create a new type. It creates a new name for the same type.

Why use typedef?

  1. Portability — Machine‑dependent types (like sizes of ints, longs, pointers) can vary across systems. Using typedefs means only one typedef block needs updating when porting code.
  2. Documentation — A typedef name can explain a concept better than a raw type, e.g. TreePtr vs. struct treeNode*.

Example: built‑in typedef size_t

size_t is defined differently on 32‑bit vs. 64‑bit platforms.

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int iArray[] = { 45, 56, 626262, 30, 2 };
    size_t iSize = sizeof(iArray) / sizeof(int);

    printf("Size of iSize: %zu\n", sizeof(iSize));
    return EXIT_SUCCESS;
}

On x64 → sizeof(size_t) = 8 bytes On x86 → sizeof(size_t) = 4 bytes

Common typedef examples

Example 1 — simple aliases

typedef int Length;

Length len1 = 5;
Length len2 = 10;
printf("%d\n", len1 + len2); // same as int

Example 2 — floating-point clarity

typedef float REAL;

REAL a = 3.14f;
REAL b = 2.5f;

Example 3 — strings

typedef char* String;

String p = "Hello world";
printf("%s\n", p);
printf("%c\n", *p);

Example 4 — unsigned types

typedef unsigned short UShort;

UShort s = 60000;
printf("%hu\n", s);

Example 5 — typedef with enum

typedef enum Boolean { False, True } BOOL;

BOOL done = False;

Where to put typedefs?

Usually in header files, so multiple source files can use the new name.

#ifndef FUNCS_H
#define FUNCS_H

typedef int Length;
typedef char* String;
typedef unsigned short UShort;

#endif

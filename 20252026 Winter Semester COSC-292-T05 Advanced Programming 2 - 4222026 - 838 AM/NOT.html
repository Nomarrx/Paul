Lesson — Bitwise NOT (~)

Learning Outcome(s): LO5 — Use bitwise operators to manipulate values safely.

Assessment alignment: Midterm 2 (Bitwise NOT & binary reasoning).

Bitwise NOT

NOT (~) inverts every bit: 1→0, 0→1. Contrast with logical NOT (!) which yields 0 or 1 only.

Example

void showBits(int value, int bytes); // from overview page

void bitInversion(void)
{
    unsigned char a = 0x48;       // 01001000
    unsigned char result = (unsigned char)(~a); // 10110111

    printf("Bitwise inversion of a is 0x%x\n", result);
    showBits(a, sizeof(char));
    showBits(result, sizeof(char));
}

What to notice

  • ~0x48 becomes 0xB7 for one byte (char).
  • Cast to the desired width when displaying/inverting subword types.
  • On signed types, beware sign-extension when promoted to int for printing.

Lesson — Structures in C: Typedef & Initialization

Learning Outcome(s): LO5 — Apply typedef with structs and initialize instances safely.

Assessment alignment: Final Exam (Structs with typedef & init lists).

Motivation: avoiding repeated struct

Writing struct TypeName everywhere is cumbersome. Use a typedef to define a convenient alias for the struct type, so you can omit the struct keyword at use sites.

Typedef of an unnamed struct

#define NAME_SIZE 64

typedef struct
{
    char cName[NAME_SIZE];
    char cGender;
    int  day;
    int  month;
    int  year;
} BirthDateTD;  // “TD” suffix to mark a typedef name

Declaring & initializing instances

// Variable with initializer list (like arrays)
BirthDateTD bd = { "Mike", 'm', 31, 12, 1980 };

// As a function parameter
void DisplayBirthDate(BirthDateTD bd);

Designated initializers (C99+)

Order-independent initialization is clearer and less error-prone:

BirthDateTD bd2 = {
    .cName = "Ada",
    .cGender = 'f',
    .day = 10,
    .month = 12,
    .year = 1815
};

Memory model note

A struct occupies a contiguous block of memory. Members may be padded for alignment. When you copy a struct variable (assignment or pass-by-value), all bytes are copied (shallow copy of the bytes).

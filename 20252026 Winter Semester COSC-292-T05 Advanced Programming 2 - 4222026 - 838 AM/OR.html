Lesson — Bitwise OR (|)

Learning Outcome(s): LO5 — Use masks to set bits and combine flags.

Assessment alignment: Midterm 1 (Bit masks / OR).

Bitwise OR

OR sets the result bit to 1 if either operand bit is 1 (or both). Logical OR is || (don’t confuse).

Example

void showBits(int value, int bytes);

void bitOR(void)
{
    unsigned char a = 0x48;      // 01001000
    unsigned char b = 0xB8;      // 10111000
    unsigned char result = (unsigned char)(a | b); // 11111000

    printf("Bitwise OR of a and b is 0x%x\n", result);
    showBits(a, sizeof(char));
    showBits(b, sizeof(char));
    showBits(result, sizeof(char));
}

Mask to force bits ON

void demoORMask(void)
{
    int x = 0x030B1A0F;
    int mask = 0xFFFF0000;     // set top 16 bits

    printf("Masked value:\t0x%x\n", x | mask);
    showBits(x, sizeof(int));
    showBits(x | mask, sizeof(int));
}

What to notice

  • Set bits: 1’s in the mask force corresponding bits to 1.
  • Signed display can appear negative if the top bit becomes 1; use unsigned for clarity.

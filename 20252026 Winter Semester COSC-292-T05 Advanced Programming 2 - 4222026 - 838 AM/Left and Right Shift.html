Lesson — Shift Operators (« and »)

Learning Outcome(s): LO5 — Use shifts to extract/pack fields and reason about signed vs unsigned shifts.

Assessment alignment: Midterm 1 (Shifts & masks).

Shifts

<< moves bits left (fills right with 0’s). >> moves bits right. Right-shift of signed integers is implementation-defined: many implementations perform arithmetic shift (pad with sign bit). Right-shift of unsigned uses logical shift (pad with 0’s).

Example

void showBits(int value, int bytes);

void shiftOperators(void)
{
    short x = 37;

    printf("No shift in x\n");
    showBits(x, sizeof(short));

    printf("Shift x 1 bit to the left\n");
    showBits(x << 1, sizeof(short)); // ~ multiply by 2

    printf("Shift x 2 bits to the right\n");
    showBits(x >> 2, sizeof(short)); // ~ integer divide by 4
}

Sign bit considerations

void shiftSignBit(void)
{
    int z = 1;

    printf("Shift z 30 bits to the left\n");
    showBits(z << 30, sizeof(int));

    printf("Shift z 31 left then 1 right (signed)\n");
    showBits(z << 31 >> 1, sizeof(int));

    // Prefer unsigned when clarity is desired:
    unsigned int u = 1u;
    printf("Unsigned shifts always pad with 0 on right shift\n");
    showBits((int)(u << 31), sizeof(int));
    showBits((int)((u << 31) >> 1), sizeof(int));
}

Nibble extraction via mask+shift

void nibbleExtract(void)
{
    unsigned char value = 0xD3; // 1101 0011
    unsigned char mask = 0x0F;  // 0000 1111

    printf("Value\n");
    showBits(value, sizeof(char));

    printf("Mask\n");
    showBits(mask, sizeof(char));

    printf("Lower nibble\n");
    showBits(value & mask, sizeof(char)); // 0x03

    printf("Upper nibble\n");
    showBits(((unsigned char)(value >> 4)) & mask, sizeof(char)); // 0x0D
}

What to notice

  • Left shift by n is roughly multiply by 2^n; right shift by n is roughly integer divide by 2^n (truncating).
  • Use unsigned types when you want right shifts to pad with 0 for sure.
  • When extracting fields, mask first or after shifts to isolate the bits you want.

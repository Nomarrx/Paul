Lesson — Unions

Learning Outcome(s): LO5 — Develop code that models and manipulates data in memory using C unions.

Assessment alignment: Final Exam (Unions, layout, and member access).

What is a union?

A union is like a struct in syntax, but **all members share the same memory region**. Only one member is intended to be valid at a time. The size of a union is the size of its **largest member**.

Example: fertilizer quantity stored in different units

Definition

typedef union
{
    unsigned char truckloads;
    unsigned int  bags;
    double        tons;
} FertilizerQuantity;

Test function

#include <stdio.h>

void testFertilizerUnion(void)
{
    FertilizerQuantity fq;

    // How big is the union in bytes?
    printf("Size of union is %zu\n", sizeof(fq)); // 8 (largest is double on typical platforms)

    // Set one member
    fq.truckloads = 3;

    printf("The value of truckloads is: %d\n",  fq.truckloads);
    printf("The value of bags is:       %u\n",  fq.bags);
    printf("The value of tons is:       %f\n",  fq.tons);

    // All members share the same base address
    printf("The address of truckloads is: %p\n", (void*)&fq.truckloads);
    printf("The address of bags is:       %p\n", (void*)&fq.bags);
    printf("The address of tons is:       %p\n", (void*)&fq.tons);

    // Now set a different member
    fq.bags = 400;
    printf("\nAfter setting bags = 400:\n");
    printf("truckloads (low byte of 400): %d\n", fq.truckloads);
    printf("bags:                         %u\n", fq.bags);

    // Now set the largest member
    fq.tons = 12345.6789;
    printf("\nAfter setting tons = 12345.6789:\n");
    printf("tons:       %f\n", fq.tons);
    printf("truckloads: %d\n", fq.truckloads);
    printf("bags:       %u\n", fq.bags);
}

What to notice

  • Shared storage: Writing one member overwrites the bytes used by the others.
  • Size equals largest member: Here, sizeof(FertilizerQuantity) matches sizeof(double).
  • Addresses: Printing addresses of each member shows they map to the same location.
  • Only the last written member is meaningful (reading a different member just reinterprets bytes).

Example: interpreting a 32‑bit color as a whole value or components

A union can present **two valid views** of the same bytes (e.g., a 32‑bit integer and a 4‑byte component struct).

Definitions

typedef struct {
    unsigned char a; // alpha (transparency)
    unsigned char b; // blue
    unsigned char g; // green
    unsigned char r; // red
} pixel32;

typedef union {
    unsigned int val;     // 32-bit packed color
    pixel32      components; // 4 one-byte components
} colorVal;

Test function

#include <stdio.h>

void testColorConversion(void)
{
    colorVal c;

    printf("Size of pixel32 is %zu\n", sizeof(pixel32));
    printf("Size of colorVal is %zu\n\n", sizeof(colorVal));

    c.val = 0x2A3BFF1C;     // set all 4 bytes at once
    c.components.a = 0xFF;  // change only the alpha byte

    printf("The whole int is %x\n", c.val);
    printf("The Red component is %x\n",   c.components.r);
    printf("The Green component is %x\n", c.components.g);
    printf("The Blue component is %x\n",  c.components.b);
    printf("The alpha channel (transparency) is %x\n", c.components.a);
}

What to notice

  • Both views are 4 bytes: sizeof(pixel32) == sizeof(unsigned int) == sizeof(colorVal) (typical ABIs).
  • Setting the val field populates all four component bytes at once.
  • Changing one component updates just that byte and thus changes val accordingly.
  • Endianness matters: The mapping of byte order between val and components depends on platform endianness and struct layout rules.

Notes & Tips

  • A union’s size equals the size of its largest member; all members start at the same address.
  • Use unions when only one representation is “active” at a time, or when you purposely reinterpret the same bytes in multiple ways.
  • When reinterpreting bytes (like the color example), remember results can be **platform‑dependent** (endianness, alignment, padding).
  • When printing addresses with %p, cast to (void*) for standard‑conforming code.

Lesson — Structures in C: Overview & Definition

Learning Outcome(s): LO5 — Develop code using C structures to model related data.

Assessment alignment: Final Exam (Structs fundamentals).

What is a struct?

A structure (record) is a user-defined data type that groups values of possibly different types into one entity. Unlike arrays (same-type elements accessed by index), struct members can have different types and are accessed by name.

  • Declared with the keyword struct.
  • Members can be primitives, pointers, arrays, other structs, and even function pointers.
  • No access modifiers (e.g., public/private) in C; no inheritance or polymorphism.

Struct declaration syntax

struct TypeName
{
    // member variable 1;
    // member variable 2;
    // ...
} /* optional variable instances here */;

Note: Adding instance variable names at the end is valid but rarely used.

Example: BirthDate record

#define NAME_SIZE 64

struct BirthDate
{
    // Attributes
    char cName[NAME_SIZE];
    char cGender;
    int  day;
    int  month;
    int  year;
};

Optional “instances at declaration” (rare in practice)

struct BirthDate
{
    char cName[NAME_SIZE];
    char cGender;
    int  day;
    int  month;
    int  year;
} B1, B2; // valid but uncommon style

Declaring variables and parameters

// As a variable:
struct BirthDate bd1;

// As a function parameter:
void DisplayBirthDate(struct BirthDate bd);

This style requires repeating the keyword struct at each use — many codebases switch to a typedef for convenience (next page).

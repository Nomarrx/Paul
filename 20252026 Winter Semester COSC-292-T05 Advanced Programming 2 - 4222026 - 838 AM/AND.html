Lesson — Bitwise AND (&)

Learning Outcome(s): LO5 — Use bitwise masks to read/clear flags.

Assessment alignment: Midterm 1 (Bit masks / AND).

Bitwise AND

AND compares bits positionally: result bit is 1 only if both operand bits are 1. Logical AND is && (don’t confuse).

Example

void showBits(int value, int bytes);

void bitAND(void)
{
    unsigned char a = 0x48;      // 01001000
    unsigned char b = 0xB8;      // 10111000
    unsigned char result = (unsigned char)(a & b); // 00001000

    printf("Bitwise AND of a and b is 0x%x\n", result);
    showBits(a, sizeof(char));
    showBits(b, sizeof(char));
    showBits(result, sizeof(char));
}

Masking patterns

void demoANDMasks(void)
{
    int x = 0x030B1A0F;            // sample value
    int maskFindBit = 0x00000004;  // test 4's bit
    int maskClearLSB = 0xFFFFFFFE; // clear bit 0

    showBits(x, sizeof(int));
    showBits(x & maskFindBit, sizeof(int));     // 0 if bit not set
    showBits(x & maskClearLSB, sizeof(int));    // clears LSB
}

What to notice

  • Preserve or clear: 1 in the mask preserves; 0 clears.
  • Test a bit: (x & (1 << n)) != 0 checks if bit n is set.
  • Prefer unsigned when working with masks to avoid sign issues.

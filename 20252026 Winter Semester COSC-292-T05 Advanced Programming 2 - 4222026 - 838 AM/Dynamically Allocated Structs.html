Lesson — Structures in C: Access & Dynamic Allocation

Learning Outcome(s): LO5 — Access struct members via dot/arrow and manage heap‑allocated structs.

Assessment alignment: Final Exam (Struct access & heap allocation).

Accessing members

Dot operator (struct variable)

BirthDateTD bd1;

bd1.day = 10;
bd1.month = 1;
bd1.year = 2000;

Pointer to struct: dereference then dot

Because . has higher precedence than *, you need parentheses if you dereference manually:

BirthDateTD* bdPtr = NULL;
bdPtr = (BirthDateTD*)malloc(sizeof(BirthDateTD));

(*bdPtr).day = 31;       // clumsy, but correct

Arrow operator (preferred)

The -> operator combines dereference + member access and is the idiomatic way to access through a pointer:

bdPtr->day = 31;
bdPtr->month = 12;
bdPtr->year = 1980;

Dynamic allocation of structs

Allocate a struct on the heap with malloc and free it with free when done. Always check for NULL.

BirthDateTD* bdPtr = (BirthDateTD*)malloc(sizeof(BirthDateTD));
if (bdPtr)
{
    bdPtr->day = 31;
    bdPtr->month = 12;
    bdPtr->year = 1980;
    // use bdPtr ...
}
free(bdPtr);
bdPtr = NULL;

Initializer helpers (optional pattern)

It’s common to write small helpers to set up structs:

BirthDateTD makeBirthDate(const char* name, char gender, int d, int m, int y)
{
    BirthDateTD bd = {0};
    strncpy(bd.cName, name, NAME_SIZE - 1);
    bd.cGender = gender;
    bd.day = d; bd.month = m; bd.year = y;
    return bd; // returns by value: copies bytes
}

Passing structs to functions

  • By value — copies the whole struct (simple, but copies bytes).
  • By pointer — pass BirthDateTD* to allow modification without copying the struct.
void DisplayBirthDateByValue(BirthDateTD bd);
void DisplayBirthDateByPtr(const BirthDateTD* bdPtr); // const: promise not to modify

Arrays of structs

Structs are contiguous in memory. Arrays of structs are contiguous sequences of those records.

BirthDateTD people[3] = {
    { "Mike",  'm', 31, 12, 1980 },
    { "Ada",   'f', 10, 12, 1815 },
    { "Chris", 'm',  1,  1, 1990 }
};

for (int i = 0; i < 3; i++)
{
    printf("%s: %02d/%02d/%04d\n",
           people[i].cName, people[i].day, people[i].month, people[i].year);
}

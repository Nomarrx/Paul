Lesson — Bitwise XOR (^)

Learning Outcome(s): LO5 — Toggle bits and implement two-way logic with XOR.

Assessment alignment: Midterm 1 (XOR & toggling/masking).

Bitwise XOR

XOR sets the result bit to 1 only if exactly one operand bit is 1. There is no logical XOR in C; ^ is bitwise.

Example

void showBits(int value, int bytes);

void bitXOR(void)
{
    unsigned char a = 0x48;      // 01001000
    unsigned char b = 0xB8;      // 10111000
    unsigned char result = (unsigned char)(a ^ b); // 11110000

    printf("Bitwise XOR of a and b is 0x%x\n", result);
    showBits(a, sizeof(char));
    showBits(b, sizeof(char));
    showBits(result, sizeof(char));
}

With masks

void demoXORMasks(void)
{
    unsigned char b = 0xB8;

    showBits(b, sizeof(char));              // original
    showBits((unsigned char)(0xFF ^ b), sizeof(char)); // invert all bits
    showBits((unsigned char)(0x00 ^ b), sizeof(char)); // preserve b (no change)
}

Common uses

  • Toggling specific bits: x ^= (1 << n);
  • Simple two-way transforms (e.g., C = P ^ K; P = C ^ K;)

Lesson — Bitwise Operators (Overview)

Learning Outcome(s): LO5 — Develop code to reference and manipulate memory with pointers and bitwise operations.

Assessment alignment: Midterm 1 (Bitwise operations & representation).

Why bitwise?

Bitwise operations work at the level of individual bits. They’re primitive CPU operations used to create masks, toggle flags, pack/unpack fields, and implement fast math and protocol logic.

Quick recap: bytes vs. bits

short sValue = 0x1234;      // hex literal
unsigned char* cPtr = (unsigned char*)&sValue;

printf("sValue: 0x%x\n", sValue);   // 0x1234
printf("sValue: %d\n", sValue);     // 4660 on typical platforms
printf("Byte 0: 0x%02x\n", cPtr[0]); // 0x34 on little-endian
printf("Byte 1: 0x%02x\n", cPtr[1]); // 0x12 on little-endian

To change specific bits inside a byte/word, we use **bitwise operators** rather than pointer byte-walking:

  • NOT ~ (invert bits)
  • AND & (mask to preserve/clear bits)
  • OR | (set bits)
  • XOR ^ (toggle bits, e.g., for two-way logic)
  • Shifts << (left), >> (right)

Helper: show bits

Use this utility to display values as binary (up to 32 bits):

// Print a value as a string of bits (up to 32 bits)
void showBits(int value, int bytes)
{
    unsigned int filter = 1;
    int bit;

    char* bitString = (char*)malloc(33);
    bitString[32] = '\0';

    for (bit = 0; bit < bytes * 8; bit++)
    {
        if (value & filter) bitString[31 - bit] = '1';
        else                bitString[31 - bit] = '0';
        filter *= 2; // next bit
    }

    printf("The value %d in binary is \t%s\n",
           value, &bitString[32 - bytes * 8]);

    free(bitString);
}
